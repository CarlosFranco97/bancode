# Proyecto: Bancode

## Descripción

Bancode es una aplicación desarrollada con JavaScript Vanilla, centrada en la manipulación del DOM para ofrecer una experiencia de usuario interactiva. Una de sus principales características es la implementación de un menú hamburguesa para mejorar la navegación.

## Características

Implementación de un menú hamburguesa con JavaScript Vanilla.

Manipulación del DOM para dinamizar la interfaz.

Diseño intuitivo con HTML5 y CSS3.

Tecnologías utilizadas

JavaScript Vanilla - Para la lógica de la aplicación.

HTML5 & CSS3 - Para la estructura y estilos de la interfaz.

## Instalación y uso

1. Clonar el repositorio:
git clone https://github.com/carlosfranco97/bancode.git

2. Acceder al directorio del proyecto:
cd bancode

3. Abrir el archivo index.html en un navegador web para ejecutar la aplicación.
